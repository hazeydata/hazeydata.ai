Key Architectural Decisions

Décisions architecturales clés

  • NemoClaw Foundation: Leverage enterprise-grade infrastructure instead of building from scratch
  • Canadian Intelligence Layer: Focus development on institutional knowledge and compliance
  • Hardware-Enforced Security: Out-of-process policy enforcement via OpenShell
  • Local-First Design: All sensitive processing stays on-premises
  • Open Source Stack: Apache 2.0 licensing ensures long-term control
  • Fondation NemoClaw : Exploiter l'infrastructure de niveau entreprise au lieu de construire à partir de zéro
  • Couche d'intelligence canadienne : Concentrer le développement sur les connaissances institutionnelles et la conformité
  • Sécurité appliquée par le matériel : Application de politique hors processus via OpenShell
  • Conception locale d'abord : Tout traitement sensible reste sur site
  • Stack open source : Licence Apache 2.0 assure le contrôle à long terme

Ce qui a changé par rapport à v2

Key Security Properties

Propriétés de sécurité clés

  • Hardware Enforcement: Policies enforced at kernel level, agent cannot override
  • Audit Everything: Every file access, network request, process spawn logged
  • Fail Secure: Default deny, explicit allow only
  • Runtime Updates: Policies can be updated without agent restart
  • ITSG-33 Mapping: Each policy maps to specific ITSG-33 security controls
  • Application matérielle : Politiques appliquées au niveau du noyau, l'agent ne peut pas contourner
  • Auditer tout : Chaque accès de fichier, requête réseau, génération de processus enregistrée
  • Échouer en sécurité : Refus par défaut, autorisation explicite seulement
  • Mises à jour d'exécution : Les politiques peuvent être mises à jour sans redémarrage de l'agent
  • Mappage ITSG-33 : Chaque politique correspond à des contrôles de sécurité ITSG-33 spécifiques

CDR Core Principles: The Constitution

Principes fondamentaux CDR : La constitution

1. Sovereignty First

1. Souveraineté d'abord

Canadian data stays in Canada. Canadian AI serves Canadian institutions. No foreign control over institutional intelligence.

Les données canadiennes restent au Canada. L'IA canadienne sert les institutions canadiennes. Aucun contrôle étranger sur l'intelligence institutionnelle.

2. Local-First

2. Local d'abord

Processing happens on-premises. Cloud is optional enhancement, never a dependency. Organizations control their own compute.

Le traitement se fait sur site. Le nuage est une amélioration optionnelle, jamais une dépendance. Les organisations contrôlent leur propre calcul.

3. Compliance by Design

3. Conformité par conception

Every tool built meets Canadian regulatory requirements automatically. ITSG-33, WCAG, OLA, privacy laws.

Chaque outil construit respecte automatiquement les exigences réglementaires canadiennes. ITSG-33, WCAG, LLO, lois sur la confidentialité.

4. Human-Agent Partnership

4. Partenariat humain-agent

Terry augments human capability, never replaces human judgment. Critical decisions require human approval.

Terry augmente la capacité humaine, ne remplace jamais le jugement humain. Les décisions critiques nécessitent l'approbation humaine.

5. Knowledge Flows, Data Never Does

5. Le savoir circule, les données jamais

Nodes share tool patterns and best practices. Raw data never leaves its source organization.

Les nœuds partagent les modèles d'outils et les meilleures pratiques. Les données brutes ne quittent jamais leur organisation source.

6. Trust But Verify

6. Faire confiance mais vérifier

Terry operates with trust, but every action is verified and logged. Hardware-enforced accountability.

Terry opère avec confiance, mais chaque action est vérifiée et enregistrée. Responsabilisation appliquée par le matériel.

Principes en pratique

Ces principes guident chaque décision technique dans CDR. Quand NemoClaw fournit la fondation, CDR assure que les principes sont respectés à travers des politiques et des flux de travail développés par le Canada. Les principes survivent à tout changement de plateforme.
