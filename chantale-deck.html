The opportunity

What We'd Be Building

The CRA publishes the T4127 — the official tax formulas that every payroll system in Canada uses to calculate deductions. Nobody publishes the equivalent for collective agreements. That's what we'd build: an API that gives Dayforce (and any pay system) the rules for 150 collective agreements in machine-readable form.

What exists today (T4127 for taxes)

  • CRA publishes tax formulas every January
  • Every payroll vendor in Canada uses them
  • Nobody questions whether this should exist
  • Small team maintains it. Government owns it.

What we'd build (T4127 for CAs)

  • Machine-readable rules for all 150 CAs
  • Dayforce calls the API for CA-specific logic
  • Bilingual, with article-level citations
  • Small team maintains it. Government owns it.

Nobody else has built this. Nobody else is building this.
The only working prototype in Canada is sitting on Fred's server.
